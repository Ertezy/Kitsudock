# Kitsudock

[English](README.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md) · **日本語** · [한국어](README.ko.md)

<img width="800" alt="Kitsudock demo" src="https://github.com/user-attachments/assets/a4309a5a-8c96-40aa-a709-6fa5117bfcb4" />

Windows 向けの無料のガチャゲーム用ランチャーです。原神、崩壊：スターレイル、ゼンレスゾーンゼロ、
鳴潮、アークナイツ：エンドフィールドに対応し、いくつものランチャーをひとつのウィンドウにまとめます。

ゲーム開発元とは関係ありません。ゲーム名とアートワークの権利は各権利者に帰属します。

## ダウンロード

### [Windows 版 Kitsudock をダウンロード](https://github.com/Ertezy/Kitsudock/releases/latest/download/Kitsudock-setup.exe)

最新版の `Kitsudock-setup.exe` です。64 ビット版の Windows 10 または 11 が必要です。すべての
バージョンと更新内容は [Releases](https://github.com/Ertezy/Kitsudock/releases) ページにあります。

## インストール

1. `Kitsudock-setup.exe` を実行します。現在のユーザーにだけインストールされ、管理者権限は
   不要です。Microsoft WebView2 がまだ入っていなければ、インストーラーが自動でダウンロードします。
2. インストーラーにはまだコード署名がないため、Windows SmartScreen が「Windows によって PC が
   保護されました」と表示することがあります。**詳細情報 → 実行** をクリックしてください。
3. 初回起動時、Kitsudock はこのパソコンで見つかったゲームを表示します。必要なものにチェックを
   入れて **選択したものを追加** をクリックします。見つからなかったゲームは、あとから
   設定 → ゲーム → **+ ゲームを手動で追加** で、ゲームの `.exe` を指定して追加できます。

## アップデート

新しいバージョンが出ると、サイドパネルの下に知らせが表示されます。そこにある **アップデート** を
クリックすると、Kitsudock が新しいインストーラーをダウンロードしてインストールし、再起動します。
ゲーム、並び順、設定はそのまま残ります。アップデートに失敗した場合は、その旨が表示され、
**ダウンロード** のリンクも出ます。

手動でのアップデートもできます。同じリンクからインストーラーをもう一度ダウンロードし、
古いバージョンの上から実行してください。

## アンインストール

Windows の設定 → アプリ → インストールされているアプリ → Kitsudock → アンインストール。
設定やキャッシュした画像も消したい場合は、アンインストーラーで「Delete the application data」に
チェックを入れるか、`%APPDATA%\io.github.ertezy.kitsudock` と
`%LOCALAPPDATA%\io.github.ertezy.kitsudock` を自分で削除してください。

## プライバシー

アカウントもテレメトリもありません。設定、キャッシュ、ログはすべてお使いのパソコンに保存され、
ログが自動で送信されることはありません。どのウェブサイトとも同じく、ダウンロード元のサーバーには
IP アドレスが見えます。

データは GitHub Pages、または自分で設定したアドレスから取得します。画像と動画はゲームの Wiki、
YouTube、HoYoPlay、Steam、Epic のサーバーから取得し、ストアのアートワークはローカルのキャッシュから
読むこともあります。動画とコード交換のリンクはブラウザーで開きます。**アップデート** をクリックすると、
このリポジトリの GitHub Releases から `latest.json` とインストーラーを取得します。

## 安全ですか？

- **ゲームの起動：** Kitsudock はゲームアカウントにログインせず、パスワードも求めず、ゲームファイルを
  変更せず、ゲームのプロセスにコードを注入することもありません。ローカルのインストール情報を読み、
  アイコンを取り出すためにゲームの `.exe` を読むことがあります。Steam と Epic のゲームはそれぞれの
  起動リンクで、その他のゲームは `.exe` を実行して起動します。ゲーム専用のランチャーを選んだ場合も
  同じ方法です。管理者権限が必要なゲームでは、Windows 標準の確認画面が表示されます。ゲームや
  ストアのランチャーがログインを求めることはあります。
- **ネットワーク：** ダウンロードと外部リンクについては [プライバシー](#プライバシー) を参照してください。
  ログは自動送信されません。
- **アップデート：** **アップデート** をクリックしたときだけ行われます。署名がアプリに組み込まれた鍵と
  一致した場合にだけインストールされ、一致しなければ何もインストールされません。
- **ソースとビルド：** ソースコードは [MIT ライセンス](LICENSE) で公開しています。インストーラーは
  このリポジトリの [リリース用ワークフロー](.github/workflows/release.yml) で、GitHub Actions 上で
  ビルドされます。
- **Windows の警告とダウンロード：** 現在インストーラーには署名がないため、SmartScreen が「認識されない
  アプリ」と警告することがあります。このリポジトリの
  [Releases ページ](https://github.com/Ertezy/Kitsudock/releases) からのみダウンロードし、アドレスが
  `github.com/Ertezy/Kitsudock` であることを確認してください。警告そのものは安全性の判定ではありません。
  詳しくは [Code signing policy](README.md#code-signing-policy) をご覧ください。

## できること

- **すべてのゲームをひとつのドックに。** Steam、Epic Games Launcher、HoYoPlay、Kuro ランチャー、
  GRYPHLINK からゲームを見つけるほか、ゲームの `.exe` を指定して追加することもできます。
  並び順は 設定 → ゲーム でドラッグして変えられます。
- **プレイ** は、ゲームをインストールしたストア経由、または直接起動します（ゲームの `.exe` を
  ダブルクリックするのと同じです）。Kitsudock はゲームファイルを変更せず、起動中のゲームにも
  関わりません。起動方法が複数あるゲームでは、**プレイ** の上の行（「直接起動 ▴」）で、直接起動、
  ゲーム専用のランチャー（HoYoPlay、Kuro ランチャー、GRYPHLINK——そのランチャーからインストール
  した場合）、ストア経由を切り替えられます。選んだ方法はゲームごとに記憶されます。
- **サイドパネル** に、選んだゲームの期限付きシリアルコード、開催中と開催予定のガチャ（カルーセルは
  自動で切り替わります）、最新の公式動画を表示します。各セクションは見出しで折りたためます。
  公式 SNS の列は端のタブに隠せます。折りたたんだ状態はすべてのゲームで共通で、再起動後も残ります。
- **言語：** 表示言語は 日本語、English、Русский、简体中文、한국어。動画は英語か日本語。
  コードの報酬やガチャ名などのデータは英語の Wiki から取得するため、英語のままです。
- **背景：** 原神、崩壊：スターレイル、ゼンレスゾーンゼロには公式 HoYoPlay の背景（アニメーションが
  オンなら動画）を使います。ストアのアートワーク、自分の画像や動画も使えます。
- **トレイ：** ウィンドウを閉じるとトレイに隠せます。トレイのメニューからゲームを起動することも
  できます。
- **Windows と一緒に起動：** トレイに隠れた状態で起動し、コードとガチャを最新に保ちます。

## データの取得元

パネルのコード、ガチャ、動画は、GitHub Actions 上で動く別のプログラムが集めて、ひとつのファイルとして
公開しています。

- リポジトリ：https://github.com/Ertezy/Kitsudock-data
- ファイル：https://ertezy.github.io/Kitsudock-data/hub.json

コミュニティの Wiki（Fandom、wiki.gg——CC BY-SA）、鳴潮の公式告知（タイトル、キャラクター、
期間などの事実のみ）、公式 HoYoPlay ランチャー（原神、崩壊：スターレイル、ゼンレスゾーンゼロの
現在の背景へのリンク）、公開されている API ミラー、各ゲームの公式 YouTube チャンネルから情報を
集めています。すべてのコードとガチャに出典へのリンクがあります。設定 → データ → データ取得元の URL
で、別のアドレスを指定することもできます。
