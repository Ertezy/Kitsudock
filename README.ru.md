# Kitsudock

[English](README.md) · **Русский**

Бесплатный лаунчер гача-игр для Windows: Genshin Impact, Honkai: Star Rail,
Zenless Zone Zero, Wuthering Waves и Arknights: Endfield — одно окно вместо нескольких
лаунчеров.

Не связан с разработчиками игр. Названия игр и арт принадлежат правообладателям.
Genshin Impact, Honkai: Star Rail и Zenless Zone Zero: © All rights reserved by HoYoverse.

## Скачать

### [Скачать Kitsudock для Windows](https://github.com/Ertezy/Kitsudock/releases/latest/download/Kitsudock-setup.exe)

Последняя версия, файл `Kitsudock-setup.exe`. Windows 10 или 11, 64-бит. Все версии с
описанием изменений — на странице [Releases](https://github.com/Ertezy/Kitsudock/releases).

## Установка

1. Запустите `Kitsudock-setup.exe`. Он ставит программу только для вашего пользователя,
   права администратора не нужны; если в системе нет Microsoft WebView2, установщик
   скачает его сам.
2. Установщик пока не подписан, поэтому SmartScreen может написать «Система Windows
   защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**.
3. При первом запуске Kitsudock покажет игры, которые нашёл на компьютере. Отметьте нужные
   и нажмите **Добавить отмеченные**. Игру, которую он не нашёл, можно добавить потом:
   Настройки → Игры → **+ Добавить игру вручную**, указав `.exe` игры.

## Обновление

Скачайте установщик по той же ссылке и запустите поверх старой версии. Игры, их порядок
и настройки сохранятся. Когда выходит новая версия, внизу боковой панели появляется строка
«Вышла версия … · Скачать».

Переходите с Gacha Hub (старое название проекта)? Сначала установите Kitsudock — игры и
настройки перенесутся при первом запуске, — потом удалите Gacha Hub — после первого запуска
Kitsudock галочку «Удалить данные приложения» можно ставить: она уберёт старые кеши.

## Удаление

Параметры Windows → Приложения → Установленные приложения → Kitsudock → Удалить. Чтобы
удалить и настройки с сохранёнными картинками, отметьте в деинсталляторе «Удалить данные
приложения» или удалите сами папки `%APPDATA%\io.github.ertezy.kitsudock` и
`%LOCALAPPDATA%\io.github.ertezy.kitsudock`.

## Приватность

В Kitsudock нет системы аккаунтов и телеметрии; журналы не отправляются автоматически.
Настройки, кеши и журналы хранятся локально. Серверы, с которых скачиваются файлы,
видят ваш IP-адрес и обычные сведения HTTP-запроса.

Программа делает HTTPS GET-запросы за файлом данных с GitHub Pages или с адреса
источника, указанного в настройках. Картинки баннеров, миниатюры YouTube и фоновые
картинки и видео скачиваются по адресам из этого файла, в том числе с вики игр
(Fandom, wiki.gg), серверов изображений YouTube и официального лаунчера HoYoPlay. Арт Steam и Epic Games берётся из локальных
кешей лаунчеров или скачивается с их серверов изображений. Адреса медиа зависят от
источника данных и установленных лаунчеров. Нажатие на видео или ссылку для активации
промокода открывает внешний сайт в вашем браузере.

## Безопасно ли это?

- **Запуск игр:** Kitsudock не входит в игровые аккаунты, не запрашивает их пароли,
  не меняет файлы игр и не внедряет код в их процессы. Он читает сведения об установленных
  играх и может прочитать исполняемый файл игры, чтобы извлечь иконку. Игры из Steam
  и Epic запускаются через их ссылки запуска, остальные — обычным запуском `.exe`.
  Если игре нужны права администратора, используется стандартное окно подтверждения
  Windows. Сама игра или лаунчер магазина могут попросить войти в аккаунт.
- **Сеть:** скачивания и внешние ссылки описаны в разделе
  [Приватность](#приватность); журналы автоматически не отправляются.
- **Исходники и сборка:** исходный код доступен по [лицензии MIT](LICENSE).
  Установщики собираются GitHub Actions из этого репозитория через
  [workflow выпуска](.github/workflows/release.yml).
- **Предупреждения Windows и скачивание:** установщики пока не подписаны, поэтому
  SmartScreen может предупредить о неизвестном приложении. Скачивайте только со
  [страницы Releases этого репозитория](https://github.com/Ertezy/Kitsudock/releases)
  и перед скачиванием проверяйте адрес `github.com/Ertezy/Kitsudock`. Само предупреждение
  не определяет безопасность файла. Подробнее — в разделе [Подпись кода](#подпись-кода).

## Что умеет

- **Все игры в одном доке.** Игры находятся через Steam, Epic Games Launcher, HoYoPlay,
  лаунчер Kuro и GRYPHLINK, или добавляются указанием `.exe` игры. Порядок меняется
  перетаскиванием в Настройки → Игры.
- **«Играть»** запускает игру через магазин, из которого она установлена, или напрямую —
  как двойной клик по `.exe`. Программа не изменяет файлы игр и с запущенной игрой не
  взаимодействует.
- **Боковая панель** выбранной игры: промокоды со сроком действия, текущие и будущие
  баннеры (карусель листается сама) и свежие официальные видео.
- **Языки:** интерфейс на русском или английском, видео на английском или японском.
- **Фон:** официальный фон HoYoPlay для Genshin Impact, Honkai: Star Rail и Zenless
  Zone Zero (видео, если включена анимация), арт из магазина, своя картинка или своё
  видео.
- **Трей:** крестик может прятать окно в трей, игры запускаются и из меню трея.
- **Запуск вместе с Windows:** программа стартует спрятанной в трей и держит коды и
  баннеры свежими.

## Откуда данные

Коды, баннеры и видео собирает отдельный сборщик на GitHub Actions и выкладывает одним
файлом:

- репозиторий: https://github.com/Ertezy/Kitsudock-data
- файл: https://ertezy.github.io/Kitsudock-data/hub.json

Сборщик читает вики сообществ (Fandom, wiki.gg — CC BY-SA), официальные анонсы
Wuthering Waves (только факты: название, персонаж, сроки), официальный лаунчер HoYoPlay
(ссылки на текущие фоны Genshin Impact, Honkai: Star Rail и Zenless Zone Zero), открытое
зеркало API и официальные YouTube-каналы игр. У каждого кода и баннера есть ссылка на
источник. Другой адрес можно указать в Настройки → Данные → Адрес источника данных.
